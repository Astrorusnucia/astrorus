# Astrorus

App de astronomía en español: qué ver esta noche, nubes y seeing, objetivos para el Dwarf 3, ocular y filtro recomendados para tu telescopio, charla guiada con voz, catálogo Messier y diario de observación.

**Abrir:** la página de GitHub Pages de este repositorio. En el móvil se puede instalar: Android/Chrome → menú ⋮ → «Instalar app»; iPhone/Safari → Compartir → «Añadir a pantalla de inicio».

Datos del tiempo: [Open-Meteo](https://open-meteo.com) (CC BY 4.0) y [7Timer!](https://www.7timer.info). Cálculos astronómicos propios.
